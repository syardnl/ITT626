# SLA targets run on 24/7 calendar time

SLA response and resolution targets count elapsed calendar minutes from when the Complaint was reported, with no pause for nights, weekends or public holidays; times are stored in UTC and displayed in Asia/Kuala_Lumpur. Office-hours SLAs would match how a management office actually staffs, but need a business-hours and holiday calendar and make breach maths harder to explain; the case study's targets (e.g. Critical: 1 h response) read as round-the-clock, so we chose calendar time.
